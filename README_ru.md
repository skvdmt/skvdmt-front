# skvdmt-front

### Translations

[En](./README.md)

### Описание

Фронтенд-приложение для моего личного сайта.

Приложение работает с бекэнд апи для получения необходимой информации для построения DOM модели документа страницы.

Реализован рендеринг на стороне сервера средствами Nuxt 4.

### Скачать

```sh
git clone https://github.com/skvdmt/skvdmt-front
```
